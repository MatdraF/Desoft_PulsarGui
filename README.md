# Desoft_PulsarGUI
Cliente: Cristóbal Espinoza Romo
## Features

- Supports loading FITS files from the Fermi LAT database, with the ability to choose among the FITS files located in the project directory.
- Visualizes pulsar data using a 2D histogram in Right Ascension (RA) and Declination (DEC).
- Integrates [PINT](https://github.com/nanograv/PINT) and `fermiphase` to produce **pulse profiles** and **phaseograms**.
- Includes a Qt-based graphical user interface (GUI) for an intuitive user experience.
